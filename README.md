# HMS (Hustle Management System)

It replaces wordpress + elementor + dynamic.ooo + woocommerce with a tanstack-start core.

It's full featured with a convex backend complete component library, drag and drop page builder that stores page structure and content as json allowing for realtime edits.

Add a page, blog post, product, or change a section, word, image and visitors see it instantly.

Timestamped revisions and split test variants are baked into the system's core allowing marketing teams to test and rollback changes in realtime.

Move fast, break stuff and hustle hard with HMS.

## Stack

- lint, format, and type check at lightning speeds with vite-plus, pnpm, oxc, and tsgo.
- rely on a single source of truth with zod objects and validation driving convex schemas with zod convex helpers.
- maintain state live across machines with zustand backed with convex session management synchronization.
- quickly rip through component construction with shadcn/ui primitives and tailwindcss.
- rest assured that build and deploy times are blasingly quick and hyper reliable thanks to tanstack-start.
- email deliverability is best-in-class built on top of resend and backed by convex.
- checkouts always complete with stripe.
- effortlessly onboard users at scale with clerk and clerk orgs.
- wcag and webaim compliance is locked into to every element at the core level with base-ui.
- tables, charts, and forms are second to none with tanstack table, chart, and form primitives layered on top of shadcn/ui styles.

Everything that can be server side rendered is allowing you to build unimaginably fast, full featured web apps that scale or simple static local seo websites and landing pages without code using only your mouse and imagination.
